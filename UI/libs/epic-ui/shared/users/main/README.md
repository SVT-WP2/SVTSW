# epic-ui/shared/users

The user management of an Admin (ticket 396): the grid of the users, the dialogs to create a user, to change its
name and role, to set its password and to switch it off. The page is `apps/epic-measure-ui/src/modules/admin/pages/users`.
The dialog of the own password is in `epic-ui/common/auth`.

## Running unit tests

Run `nx test epic-ui/shared/users` to execute the unit tests.
